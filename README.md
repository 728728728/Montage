# Montage — 写真ムービー

写真と音楽から、おしゃれな横長（16:9）のムービーをつくる自分専用のWebアプリ。スマホでの編集が前提。

- 写真・音楽・作品は **端末の中（IndexedDB）だけ** に保存され、どこにも送信しない
- ホーム画面に追加すると全画面のアプリとして使える（PWA・オフライン対応）

## できること

- **テーマ7種**：シネマティック / 8ミリフィルム / エディトリアル / ポラロイド / キネティック / ミニマル / ドリーミー
- 写真ごとに **表示秒数**・動き（ズーム・パン・寄せる場所）・見せ方・次への切り替え・文字
- 切り替え11種（クロスフェード・暗転・白フラッシュ・ズーム・ウィップ・ワイプ・フィルムバーン・グリッチ・ぼかし・スライド・アイリス）
- タイトルカード（オープニング・エンディング・章の区切り）、フォント7種、日付スタンプ
- 音楽：使う部分の指定、音量・フェード、**テンポ自動検出とビートに合わせた自動カット**、曲の長さに合わせる
- 仕上げ：カラー10種、粒子・周辺の暗さ・光漏れ・動きの強さ・シネマの黒帯
- 元に戻す／やり直す、自動保存
- **MP4 書き出し**（1080p / 720p、24 / 30fps）。WebCodecs 対応端末はコマ単位で高速に、非対応端末は再生しながら録画

## 構成

ビルド不要の素の HTML / CSS / JavaScript（ES Modules）。

| ファイル | 役割 |
|---|---|
| `js/app.js` | 画面と操作 |
| `js/engine.js` | 1コマ分の映像と文字を組み立てる |
| `js/renderer.js` | WebGL（配置・切り替え・色・粒子） |
| `js/overlay.js` | 文字（Canvas 2D） |
| `js/layout.js` | 写真の配置と動きの計算 |
| `js/themes.js` | テーマ・フォント・カラー |
| `js/model.js` | データ構造と時間軸 |
| `js/audio.js` | 再生・波形・ビート検出・ミックス |
| `js/media.js` | 写真と音楽の取り込み |
| `js/exporter.js` | MP4 書き出し（`vendor/mp4-muxer.mjs` を使用） |
| `js/version.js` | バージョンと更新履歴 |

変更したら `js/version.js` の `APP_VERSION` を上げ、`sw.js` の `CACHE` 名も合わせて変える。

## ローカルで動かす

```
python -m http.server 8771 --directory Montage
```

http://localhost:8771 を開く。
